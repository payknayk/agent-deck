# AGENT DECK

Статический дашборд по данным локального рантайма **MiniMax Code**: запущенные ИИ-агенты, их сессии, модели, расход токенов и полный контекст переписки — плюс загрузка собственных контекстов прямо в браузере.

Сайт не имеет бэкенда: это чистые статические файлы, которые можно положить на любой хостинг.

---

## Что внутри

| Раздел | Что делает |
|---|---|
| **Hero + KPI** | Агенты, запуски, сообщения, токены — по снимку рантайма |
| **Агенты** | Карточки ролей: описание, персона, модель, число запусков/сообщений/токенов |
| **Реестр запусков** | 112 сессий рантайма: статус, модель, рабочая папка, токены; фильтры по статусу/агенту, поиск, сортировка |
| **Панель контекста** | Полная переписка выбранной сессии: сообщения, «мысли», вызовы инструментов с аргументами и результатами; поиск, копирование, экспорт в `.md` / `.json` |
| **Экспорт (шапка)** | Меню выгрузки: снимок данных `.json`, реестр запусков `.csv` (с учётом фильтров), все контексты одним `.json`, весь сайт одним `.html` |
| **Экспорт агента** | Иконка в карточке агента — все его запуски с контекстами одним `.md` |
| **Загрузка контекста** | Drag &amp; drop своих файлов (`.md`, `.txt`, `.json`, `.csv`, `.log`), привязка к агенту / запуску / общему архиву, предпросмотр, сборка бандла `.md` / `.json` |
| **Импорт снимка** | Кнопка в шапке: подгружает свежий `snapshot.json` и перерисовывает дашборд без передеплоя |

Интерфейс двуязычный (RU/EN), есть тёмная и светлая тема.

## Приватность

- Загруженные пользователем файлы читаются через File API и хранятся **только в IndexedDB браузера** — они никуда не отправляются и живут до очистки хранилища.
- Контексты из снимка рантайма **опубликованы в открытом доступе** и содержат реальные рабочие пути, сообщения и данные. Если нужно наоборот — пересоберите снимок с маскированием (см. ниже).

## Как обновить данные

Снимок собирается из локальной базы рантайма `C:\Users\spay\.minimax\v2\sqlite\runtime-state.sqlite`
(только чтение) и из конфигов агентов `C:\Users\spay\.minimax\agents\.builtin\*\agent.md`.

```powershell
# полный сырой контекст
python tools\build_snapshot.py

# с маскированием путей, ключей и почты
python tools\build_snapshot.py --redact

# другой каталог вывода
python tools\build_snapshot.py --out data
```

Скрипт пишет `data/snapshot.json` и `data/contexts/<session_id>.json`.
Глубина контекста: свежие сессии (до 7 дней) — до 400 сообщений, до 30 дней — 60, старше — 30.
Результаты вызовов инструментов обрезаются до 20 000 символов.

Готовый снимок можно загрузить прямо на сайте кнопкой «Импорт снимка» — деплой для этого не нужен.

## Локальный запуск

```powershell
python -m http.server 8765 --bind 127.0.0.1
# http://127.0.0.1:8765/
```

Через `file://` не заработает: данные подгружаются через `fetch`.

## Публикация

`dist/` — самодостаточная статика: `index.html` в корне, `assets/`, `data/`.
Исходники проекта (`tools/`, `src`-подобные файлы) выгружаются отдельно в приватное хранилище.
